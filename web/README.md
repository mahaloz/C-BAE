# C-BAE Results dashboard

The dashboard reports function-name recovery accuracy, runtime, cost, and
trace-level audit evidence from completed C-BAE runs. Its function audit pairs
the preserved model trace with current pseudocode generated by IDA Pro.

From the repository root, regenerate the static data bundle after new runs or
regrades:

```bash
cd web
npm run data:generate
```

Then use `npm run dev` for local development, `npm run build:pages` for the
GitHub Pages static export, or `npm test` to verify the overview and run-detail
routes. The repository workflow publishes `web/out` after relevant pushes to
`main`.

The generated bundle contains private grading truth. Only publish it to an
audience authorized to inspect that truth.
